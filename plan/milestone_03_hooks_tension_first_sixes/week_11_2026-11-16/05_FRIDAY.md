**Формат:** Дом / теория  
**Тема недели:** Неглубокий drop knee  
**Главный cue:** Стопа остаётся стабильной, бедро разворачивается; глубина минимальна, достаточна только для движения.  
**Обязательное время сегодня:** примерно 36 минут (физиотерапия и воскресные варианты считаются отдельно).

> Отсчёт времени идёт от начала текущего блока, а не от часов на стене. Если переносишь день, сохрани порядок блоков и правила восстановления.

## Чек-лист по минутам

- [ ] **00:00–03:00 · Самопроверка · обязательно** — Оцени утреннюю реакцию после четверга: пальцы/плечо/колено 0–10. Запиши, восстановилась ли обычная сила кисти.
  - Интенсивность: Без нагрузки.
  - Осторожность: Острая локальная боль пальца или усилившаяся боль плеча = воскресенье только восстановительное.
- [ ] **03:00–11:00 · Теория · обязательно** — Пересмотри ключевой фрагмент ресурса недели: [R12: BMC — How to use a drop knee when climbing](https://thebmc.co.uk/en/how-to-use-a-drop-knee-when-climbing-video). Задача: Мелкий drop knee с контролируемым разворотом; для правого колена только без боли и без глубокого скручивания.
  - Интенсивность: Без нагрузки.
- [ ] **11:00–17:00 · Ментальная репетиция · обязательно** — Закрой глаза и 3 раза мысленно пройди одну рабочую трассу: руки → ноги → положение таза → дыхание. Визуализируй cue «Стопа остаётся стабильной, бедро разворачивается; глубина минимальна, достаточна только для движения.».
  - Интенсивность: Без нагрузки.
- [ ] **17:00–29:00 · Домашняя мобильность · обязательно** — Выполни H3 «Мобильность таза и контроль корпуса» — 12 минут.
  - Интенсивность: RPE 2–3.
  - Осторожность: Никаких скручиваний через боль. Плечом не отталкивайся от стены; касание только для равновесия.
- [ ] **29:00–49:00 · Физиотерапия · по назначению физиотерапевта** — Выполни свой назначенный комплекс, если пятница входит в расписание физиотерапевта.
  - Интенсивность: По назначению.
  - Осторожность: Не добавляй упражнения из интернета поверх назначений.
- [ ] **49:00–53:00 · Журнал · обязательно** — Запиши одну вещь, которая сработала на этой неделе, и одну, которую повторишь в воскресенье на лёгкой трассе.
  - Интенсивность: Без нагрузки.
- [ ] **53:00–56:00 · Запрет лишней нагрузки · обязательно** — Подтверди: сегодня нет домашнего фингерборда, висов на турнике, тяжёлых подтягиваний, farmer carry или эспандера-сжимателя.
  - Интенсивность: Восстановление.
  - Осторожность: Общая пальцевая нагрузка уже получена в четверг.

## Ресурс дня

- **[R12: BMC — How to use a drop knee when climbing](https://thebmc.co.uk/en/how-to-use-a-drop-knee-when-climbing-video)**
- Практическая задача: Мелкий drop knee с контролируемым разворотом; для правого колена только без боли и без глубокого скручивания.
- После просмотра не добавляй новые упражнения; вынеси один cue на стену.

## Когда закончить раньше

- [ ] Останови тяжёлый блок после **двух попыток подряд, которые явно хуже предыдущих**.
- [ ] Останови пальцевую нагрузку при острой локальной боли, щелчке/«попе», отёке или внезапной потере силы.
- [ ] Смени трассу при боли плеча в press/mantle, широкой компрессии или болезненном lock-off.
- [ ] Уменьши/убери high step, heel hook или drop knee, если правое колено болит или ощущается скручивание.
