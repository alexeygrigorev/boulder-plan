# Как выбирать трассы

[← Общий индекс](../README.md)

Точные линии в Berta меняются, поэтому план задаёт **критерии**, а не цвет/номер конкретного сета.

## Уровни для этого плана

| Роль трассы | Berta | Оценочный шанс успеха | Лимит |
|---|---:|---:|---|
| Разминка | 1–2 | 95–100% | без борьбы |
| Техника | 2–3 | 90%+ | обычно 2 чистых прохода |
| Объём | 4 | около 60–90% | максимум 2 попытки |
| Рабочая | 5 | около 30–70% | 2–3 попытки |
| Проект | 6 | 0–30% | 4–6 качественных попыток, 4–5 мин отдыха |

Цифры другого зала не сравнивай напрямую. В Basement/новом зале выбирай по вероятности успеха и стилю.

## Карточка выбора технической трассы

- [ ] Уровень 2–3.
- [ ] 6–10 движений.
- [ ] Можно остановиться и думать.
- [ ] Тема недели встречается минимум два раза.
- [ ] Нет обязательного болезненного press/mantle.
- [ ] Для knee-темы есть безопасный неглубокий вариант.
- [ ] Зона падения свободна.

## Карточка выбора проекта

- [ ] Движения выглядят возможными, хотя трасса пока не закрывается.
- [ ] Нет обязательной жёсткой ловли или сильного толкания плечом.
- [ ] Crux можно анализировать с земли/видео.
- [ ] Трасса, вероятно, останется на стене несколько тренировок.
- [ ] Можно дать 4–5 минут отдыха, не мешая другим.
- [ ] Есть безопасный спуск или контролируемое падение.

## Как использовать BETA7

1. Сохрани трассу и первую гипотезу.
2. Сделай 2–3 собственные попытки.
3. Только затем посмотри подсказку/beta-видео.
4. Не копируй движение автоматически: учти свой рост, мобильность, плечо и колено.
5. В трекере запиши не «увидел бету», а конкретное изменение: например, «левая стопа выше, таз вправо».

## Когда сменить трассу

- движение болезненно;
- две попытки подряд стали хуже;
- пальцы уже не держат обычную кромку;
- ты повторяешь без новой гипотезы;
- очередь/зона падения не позволяют работать безопасно.

Смена трассы — часть плана, а не поражение.
