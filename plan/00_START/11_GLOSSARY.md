# Словарь

[← Общий индекс](../README.md)

| Термин | Простое объяснение |
|---|---|
| Beta | Способ прохождения: последовательность рук, ног и положений тела |
| Crux | Самое трудное движение или участок |
| Flash | Проход с первой попытки |
| Project | Трасса, над которой работаешь несколько попыток/сессий |
| Quiet feet | Точная бесшумная постановка стопы |
| Flagging | Свободная нога уравновешивает тело |
| Smearing | Давление подошвой в стену/объём без явной ступеньки |
| Backstep | Наружное ребро стопы + разворот бедра к стене |
| High step | Высокая постановка ноги |
| Rock-over | Перенос таза над высокой стопой и вставание ногой |
| Foot swap | Смена ног на одной ступени |
| Heel hook | Зацеп пяткой с активной тягой |
| Toe hook | Зацеп верхней частью носка |
| Bicycle | Противодавление двумя ногами вокруг зацепа/объёма |
| Drop knee | Разворот бедра и неглубокое опускание колена внутрь |
| Body tension | Давление через стопы и корпус, удерживающее тело у стены |
| Open grip | Более открытые пальцы, без накрывания указательного большим |
| Half crimp | Согнутая позиция пальцев без большого пальца поверх указательного |
| Full crimp | Большой палец накрывает указательный; на фингерборде плана не используется |
| Edge | Кромка/полка |
| Sloper | Округлая зацепка без явной кромки |
| Pinch | Зацеп, сжимаемый большим пальцем против остальных |
| Gaston | Боковое давление рукой наружу; может быть требовательно к плечу |
| Lock-off | Удержание тела на заметно согнутой руке |
| Mantle / press | Дожим/вставание через толкание рукой |
| Deadpoint | Контролируемая динамика с захватом около верхней точки движения |
| Dyno | Прыжок с отрывом ног/тела; в этом цикле не является приоритетом |
| RPE | Субъективная трудность по шкале 1–10 |
| Pump | Утомление/«забитость» предплечий |
