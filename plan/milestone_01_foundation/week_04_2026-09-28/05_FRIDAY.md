# Неделя 04 · Пятница · 2 октября 2026

[← Обзор недели](00_WEEK_OVERVIEW.md) · [Общий индекс](../../README.md) · [Безопасность](../../00_START/02_SAFETY_AND_AUTOREGULATION.md) · [Библиотека упражнений](../../00_START/04_EXERCISE_LIBRARY.md)

**Формат:** Дом / теория  
**Тема недели:** Разгрузка и закрепление  
**Главный cue:** Заканчивай подход, пока техника ещё аккуратная, а не после полного отказа пальцев.  
**Обязательное время сегодня:** примерно 38 минут (физиотерапия и воскресные варианты считаются отдельно).

> Отсчёт времени идёт от начала текущего блока, а не от часов на стене. Если переносишь день, сохрани порядок блоков и правила восстановления.

## Чек-лист по минутам

- [ ] **00:00–03:00 · Самопроверка · обязательно** — Оцени утреннюю реакцию после четверга: пальцы/плечо/колено 0–10. Запиши, восстановилась ли обычная сила кисти.
  - Интенсивность: Без нагрузки.
  - Осторожность: Острая локальная боль пальца или усилившаяся боль плеча = воскресенье только восстановительное.
- [ ] **03:00–13:00 · Теория · обязательно** — Посмотри/прочитай второй ресурс недели: [R14: BMC — How to start fingerboarding](https://www.thebmc.co.uk/en/how-to-start-fingerboarding-with-gb-climbing-coach-rachel-carr-video). Задача: Только техника положения кисти/плеча. Не копировать чужую тяжёлую программу: в плане используется облегчённый вис с ногами.
  - Интенсивность: Без нагрузки.
- [ ] **13:00–19:00 · Ментальная репетиция · обязательно** — Закрой глаза и 3 раза мысленно пройди одну рабочую трассу: руки → ноги → положение таза → дыхание. Визуализируй cue «Заканчивай подход, пока техника ещё аккуратная, а не после полного отказа пальцев.».
  - Интенсивность: Без нагрузки.
- [ ] **19:00–31:00 · Домашняя мобильность · обязательно** — Выполни H3 «Мобильность таза и контроль корпуса» — 12 минут.
  - Интенсивность: RPE 2–3.
  - Осторожность: Никаких скручиваний через боль. Плечом не отталкивайся от стены; касание только для равновесия.
- [ ] **31:00–51:00 · Физиотерапия · по назначению физиотерапевта** — Выполни свой назначенный комплекс, если пятница входит в расписание физиотерапевта.
  - Интенсивность: По назначению.
  - Осторожность: Не добавляй упражнения из интернета поверх назначений.
- [ ] **51:00–55:00 · Журнал · обязательно** — Запиши одну вещь, которая сработала на этой неделе, и одну, которую повторишь в воскресенье на лёгкой трассе.
  - Интенсивность: Без нагрузки.
- [ ] **55:00–58:00 · Запрет лишней нагрузки · обязательно** — Подтверди: сегодня нет домашнего фингерборда, висов на турнике, тяжёлых подтягиваний, farmer carry или эспандера-сжимателя.
  - Интенсивность: Восстановление.
  - Осторожность: Общая пальцевая нагрузка уже получена в четверг.

## Ресурс дня

- **[R14: BMC — How to start fingerboarding](https://www.thebmc.co.uk/en/how-to-start-fingerboarding-with-gb-climbing-coach-rachel-carr-video)**
- Практическая задача: Только техника положения кисти/плеча. Не копировать чужую тяжёлую программу: в плане используется облегчённый вис с ногами.
- После просмотра не добавляй новые упражнения; вынеси один cue на стену.

## Когда закончить раньше

- [ ] Останови тяжёлый блок после **двух попыток подряд, которые явно хуже предыдущих**.
- [ ] Останови пальцевую нагрузку при острой локальной боли, щелчке/«попе», отёке или внезапной потере силы.
- [ ] Смени трассу при боли плеча в press/mantle, широкой компрессии или болезненном lock-off.
- [ ] Уменьши/убери high step, heel hook или drop knee, если правое колено болит или ощущается скручивание.
